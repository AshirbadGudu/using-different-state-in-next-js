This is a [Next.js](https://nextjs.org) project bootstrapped with bellow command

```sh
bun create next-app
```

## About

This project explores and compares different state management solutions in Next.js:

- **Native useState** - React hooks
- **Native useReducer** - React hooks
- **Native Context API** - React's built-in state sharing
- **Zustand** - Lightweight and flexible state management
- **Redux Toolkit** - Predictable state container
